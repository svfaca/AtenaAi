# Checklist rápido para agentes

Antes de iniciar uma tarefa, confirmar:

- [ ] entendi o problema e o escopo
- [ ] localizei os arquivos mais relevantes
- [ ] verifiquei se a mudança afeta frontend, backend ou ambos
- [ ] confirmei se há documentação pré-existente relevante
- [ ] implementei a menor correção possível
- [ ] validei o comportamento com build, teste ou inspeção
- [ ] documentei alterações importantes se necessário

## Checklist de segurança

- [ ] não alterei arquivos de legado sem necessidade
- [ ] não expus segredos ou chaves
- [ ] mantive compatibilidade com autenticação e upload

## Checklist de imagem/avatar

- [ ] confirmei se a URL é absoluta ou relativa
- [ ] confirmei se a base da API está sendo anexada corretamente
- [ ] validei o endpoint no backend
- [ ] confirmei se o arquivo existe no storage
